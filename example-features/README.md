# Example features

These complete starting points use the current direct app-proxy request. Copy the recipe closest to your storefront feature, then replace the illustrative fields with the merchant's real product and data model.

- [Shopify quiz profiles](shopify-quiz-profiles.md) — replace a structured customer profile with the shopper's latest quiz answers.
- [Shopify Klaviyo sync](shopify-klaviyo-sync.md) — save preference properties in Shopify and optionally map them to Klaviyo.
- [Shopify customer wishlist](wish-list.md) — add and remove stable product handles from a customer-owned list.
- [Saved product configurations](saved-product-configurations.md) — save, update, remove, and reopen named product designs.
- [Shopify vehicle garage](shopify-vehicle-garage.md) — add, select, and remove structured vehicles for fitment UI.
- [Shopify product registration](customer-product-registration.md) — validate and append serial registrations to a cumulative array.

For a smaller request walkthrough, start with [Quick Start](../quick-start.md). Existing non-recipe examples remain available in this section's navigation.
